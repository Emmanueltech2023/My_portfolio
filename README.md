# 🚀 PAMMY'S DEV | Full-Stack Portfolio

An immersive, high-performance portfolio built with **Next.js**, **Framer Motion**, and **Tailwind CSS**. Designed with a focus on cinematic transitions and "hacker-style" aesthetics.

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Animations:** Framer Motion (Scroll-driven & Spring physics)
- **Smooth Scroll:** Lenis
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Form Handling:** Formspree API

## ✨ Key Features
- **Hacker Intro:** A custom glitching preloader with organic SVG transitions.
- **Magnetic Physics:** Interactive UI elements that "pull" toward the cursor.
- **Sticky Project Stack:** Scroll-linked card animations with dynamic scaling.
- **Responsive Design:** Fully optimized for mobile with stacked layout logic.
- **Dark Mode:** Deep obsidian aesthetic for a premium developer feel.
